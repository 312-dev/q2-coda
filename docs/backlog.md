| EQ: measure on a device first | [internals.md: Parametric EQ](internals.md#parametric-eq) | Instruction counts are measured (about 913 MIPS instructions per stereo frame at 10 bands, 2,474 at 30); still needed: `hciplayer`'s CPU time on a device at 44.1 to 384 kHz, the word length reaching the DAC for a 16-bit file with the EQ on, and a clipping count over real music. These decide the items marked "after measurement" |
| EQ: block processing (after measurement) | | Band-outer loop with both stereo channels in the inner loop: 2.6 to 3.1 times fewer instructions, bit-identical output on prototypes; then the denormal flush once per block. Compiler flags alone gain about 1% |
| EQ: clipping and dither (after measurement) | | Auto preamp can still exceed full scale on synthetic signals (up to +1.6 dBFS); a clip counter first, a margin or soft limiter only if real music clips. Dither only if 16-bit sources reach the DAC as undithered 16-bit |
| EQ: more filter types, Rockbox export, preset management | | Low-pass, high-pass, notch, band-pass, all-pass and slope shelves; Rockbox `.cfg` export (the device dual-boots it); saving over the loaded preset, A/B, a level-matched bypass |
| The player's own TLS and decoders | [player-plan.md](player-plan.md) | A new player built from source, `q2player`, is replacing `hciplayer` ([player-plan.md](player-plan.md): phase 1 of 7 is done), which answers this item with current libraries; what follows is the in-place alternative, kept in case that work stops. `hciplayer` is MPlayer with its own static FFmpeg (3.0 by its banners, [player.md](player.md#what-it-is)) and OpenSSL 1.0.1 in a stripped 7.6 MB binary, which no library upgrade reaches. Patch it in place, as Q2 Pod already does: (1) a host-name check after the TLS handshake, done by payload code reading the peer certificate (days); (2) drop the formats it never needs from its built-in demuxer and decoder lists, so old code for obscure formats is unreachable (days); (3) redirect its FFmpeg entry points to the patched shared FFmpeg 4.2.x (weeks; each entry point must first be identified in the stripped binary). Replacing the player outright means rebuilding Shanling's glue (the command protocol `demo` uses, DSD and SACD, output routing, Tidal, AirPlay and DLNA queues, QQ Music decryption) and porting Q2 Pod's player patches to source: worth it only with Shanling's GPL source (requested); no Q2 GPL source is published (searched 2026-11-13), and the M1 Plus project above has notes on the same player |
| Server library (Local + Server) | [server-library.md](server-library.md) | A card-app catalogue extension. Firmware built on branch `feat/server-library` and the Subsonic app's side on `feat/q2-catalogue`; left: a device run with a real server, and the risks the doc lists. Read first: [shanling-m1plus-navidrome](https://github.com/shivaluma/shanling-m1plus-navidrome) (MIT), native Navidrome in the stock UI of the Shanling M1 Plus, which runs the same `demo`, AWTK and `hciplayer` stack |
| Ratings sync with OpenSubsonic | [server-library.md: Ratings and favourites](server-library.md#ratings-and-favourites) | Hearts to `setRating`, five hearts also `star`; offline changes queued on the card. Built with the server library (`ratings.out`, `ratings.in`), on the same branches |
| Now Playing centre cycle and power holds | | A centre press on Now Playing cycles the scrubber, a wheel rating view (0 to 5 hearts) and shuffle, as on an iPod; turning the screen off moves to a short centre hold and Shut Down stays on the long hold; a Sleep row as a fallback. Its own branch after the OLED theme, since both touch `navigation.c` |
| Speaker sounds through the MCU (device needed) | [hardware](hardware.md), [mcu-sleep](mcu-sleep.md) | The buzzer is PWM on the X2000's built-in MCU, whose 16 KB firmware (`/usr/data/libmcu-bare.bin`, loaded at boot by `cmd_mcu write_firmware`) knows one string, `buzzer`, at a fixed frequency and length. Patch or replace it to accept a frequency and duration so the speaker can give a wheel click, a longer button click and a beep. The emulator cannot run the MCU: `--dev` only until proven on a device |
